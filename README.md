# student-performance-analysis
Данный репозиторий содержит код и результаты разведочного анализа данных (EDA) на основе набора Student Depression Dataset. Цель проекта — выявить статистически значимые факторы, влияющие на академическую успеваемость (GPA) и уровень депрессии среди студентов, и предложить обоснованные рекомендации для служб поддержки учащихся.
